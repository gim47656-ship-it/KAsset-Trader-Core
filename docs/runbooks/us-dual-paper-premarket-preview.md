# US dual-paper KIS preview — 운영 종료

KIS cutover로 `alpaca_paper + kis_mock` dual preview profile, KIS credential 주입과 smoke 절차는 폐기되었다. 관련 KIS mock 도구는 MCP에 등록되지 않으며 KIS-only preview를 다른 provider 결과로 합성하지 않는다.

Alpaca paper는 독립 `us-paper` profile에서만 사용한다. NH PLUG는 KR mock read-only이므로 US paper/order preview 대체로 사용하지 않는다. 기존 preview packet과 ledger는 원래 provider provenance로 보존한다.
